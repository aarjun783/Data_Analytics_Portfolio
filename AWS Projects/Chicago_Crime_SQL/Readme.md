**Chicago Crime Analysis with AWS, Tableau and SQL**

**Purpose** : To analyse crime hotspots and trends in crimes over time in Chicago from 2015 to 2025

**Tech Stack** : Amazon S3 (File storage), Amazon Glue Crawler (Database creation), Amazon Athena (SQL Querying)
